HOW TO PICK

툴 고르기 전 3가지 질문

  1. 결과물이 뭔가요? — 글, 이미지, 영상, 소리, 화면 중 하나로 좁혀요.
  2. 내 자료를 넣어야 하나요? — 그렇다면 파일을 올릴 수 있는 툴(ChatGPT, Claude, NotebookLM 등).
  3. 최신 정보가 필요한가요? — 그렇다면 출처를 보여주는 검색형(Perplexity 등)으로 확인해요.
하나만 고른다면 범용 AI 비서(ChatGPT·Claude·Gemini 중 하나) 하나를 깊게 쓰는 게 툴 열 개를 얕게 쓰는 것보다 훨씬 나아요. 나머지는 필요할 때 더하세요.

TOOL MAP

목적별 툴 지도

GPT
ChatGPT

가장 범용적인 AI 비서. 글쓰기, 아이디어, 이미지 생성, 파일 분석까지 한곳에서.

초안 쓰기아이디어이미지 생성
C
Claude

긴 글과 문서 작업에 강해요. 보고서·기획서 정리, 글 다듬기, 코드 작성에 자주 써요.

긴 문서글 다듬기코드
G
Gemini

구글 서비스(지메일, 드라이브, 문서)와 잘 이어져요. 구글 업무 환경이라면 편해요.

구글 연동요약리서치
P
Perplexity

답마다 출처 링크를 달아 주는 검색형 AI. 최신 정보를 찾을 때 좋아요.

출처 있는 검색시장 조사
NB
NotebookLM

내가 올린 자료(PDF, 문서, 링크)만 근거로 답해요. 자료 공부·강의 준비에 좋아요.

내 자료 요약학습
MJ
Midjourney

감성적이고 완성도 높은 이미지. 브랜드 무드 보드, 콘셉트 이미지에 강해요.

무드 이미지콘셉트 아트
ID
Ideogram

이미지 안에 글자를 비교적 잘 넣어요. 포스터·썸네일 시안에 유용해요.

글자 있는 이미지썸네일 시안
K
Kling AI

이미지·텍스트로 영상을 만들어요. 제품 광고, 숏폼 영상 소스에 많이 써요.

이미지→영상광고 영상
R
Runway

영상 생성과 편집 기능을 함께 갖춘 툴. 배경 지우기 등 편집 기능도 있어요.

영상 생성영상 편집
V
Google Veo

구글의 영상 생성 모델. Gemini 앱 등에서 쓸 수 있어요.

영상 생성
CC
CapCut

자동 자막, 템플릿, 음악까지 되는 편집 앱. 숏폼 마무리 편집용으로 가장 쉬워요.

숏폼 편집자동 자막
VR
Vrew

말소리를 인식해 한국어 자막을 자동으로 만들어요. 강의·인터뷰 영상에 편해요.

한국어 자막강의 영상
11
ElevenLabs

자연스러운 AI 음성(내레이션). 여러 언어 지원.

내레이션더빙
TC
Typecast

한국어 AI 성우 목소리가 다양해요. 국내 콘텐츠 내레이션에 많이 써요.

한국어 성우
S
Suno

가사와 분위기만 적으면 노래·배경음악을 만들어요.

배경음악징글
F
Figma

UI 디자인의 기본 툴. AI 기능으로 시안 생성, 이름 정리 등을 도와줘요.

UI 디자인프로토타입
CV
Canva

템플릿 기반 디자인. 카드뉴스, 썸네일, 상세페이지를 빠르게 만들 때.

카드뉴스썸네일
GM
Gamma

글만 넣으면 발표 슬라이드 초안을 만들어 줘요.

슬라이드제안서
N
Notion AI

노션 안에서 요약, 글쓰기, 회의록 정리를 해줘요.

회의록문서 정리
LV
Lovable · v0

말로 설명하면 웹 화면을 코드로 만들어 줘요. 아이디어 시제품을 빠르게.

웹 시제품랜딩페이지

해당하는 툴이 없어요.

RECIPES

작업별 툴 조합 레시피

✍️ 블로그 글 1편리서치 → 초안 → 썸네일
  1. Perplexity로 주제 관련 최신 자료와 출처 모으기
  2. ChatGPT·Claude에 자료를 붙여넣고 개요 → 초안 쓰기
  3. 초안에 내 경험·사례를 직접 넣어 다듬기 (여기가 가장 중요해요)
  4. Canva·Ideogram으로 썸네일 만들기
🎬 15초 광고 영상기획 → 이미지 → 영상 → 편집
  1. ChatGPT·Claude로 3컷 구성과 자막 기획
  2. Midjourney·ChatGPT 이미지·Kling 이미지로 컷별 기준 이미지
  3. Kling AI로 이미지를 5초 영상으로
  4. CapCut으로 이어 붙이고 자막·음악 넣기

자세한 방법은 자료실의 「Kling AI 광고 영상 제작 가이드」를 보세요.

🎓 강의 자료 1세트자료 정리 → 목차 → 슬라이드
  1. NotebookLM에 참고 자료를 올려 핵심 정리
  2. Claude·ChatGPT로 학습 목표와 목차, 실습 설계
  3. Gamma로 슬라이드 초안 → 피그마·키노트에서 다듬기
  4. Vrew로 녹화 강의 자막 넣기
📱 앱 아이디어 시제품기획 → 화면 → 동작하는 시제품
  1. ChatGPT·Claude로 문제 정의와 핵심 기능 3개 정리
  2. Figma로 주요 화면 3~5개 그리기
  3. Lovable·v0 같은 툴로 실제로 눌러볼 수 있는 시제품 만들기
  4. 지인 5명에게 써보게 하고 피드백 받기

아이디어 검증은 자료실의 「AI로 하는 앱 아이디어 검증 워크북」과 함께 쓰면 좋아요.
