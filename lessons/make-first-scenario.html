LEARNING LAB · 초급 10

Make 첫 자동화 만들기

폼 응답이 오면 시트에 기록하고 메일을 보내는 첫 자동화를 직접 만들어요.

초급자동화·제작약 25분실습 포함

WHY

이 레슨에서 얻는 것

자동화는 어려워 보이지만 '무슨 일이 생기면(트리거) → 무엇을 한다(액션)'의 연결이에요. 가장 쉬운 자동화 하나를 직접 만들어 보면, 내 업무 중 무엇을 맡길 수 있는지 눈에 보이기 시작해요.

CONCEPTS

먼저 알아둘 개념

시나리오

Make에서 자동화 하나를 부르는 이름이에요.

트리거

자동화를 시작하는 사건. 예) 폼에 새 응답이 들어옴

모듈

각 단계의 작업 블록. 예) 시트에 한 줄 추가, 메일 보내기

매핑

앞 단계의 값(이름·이메일)을 다음 단계 칸에 끌어다 넣는 것

STEP BY STEP

따라 하기 5단계

  1. 준비하기
    Make 무료 계정을 만들고, 구글 폼(이름·이메일·관심 분야)과 빈 구글 시트(같은 열 제목)를 만들어요.
  2. 트리거 연결
    새 시나리오 → + 버튼 → Google Forms → Watch Responses. 구글 계정을 연결하고 폼을 골라요.
  3. 시트에 기록
    + → Google Sheets → Add a Row. 시트를 고르고, 열마다 폼 응답 값을 매핑해요.
  4. 메일 보내기
    + → Gmail → Send an Email. 받는 사람에 폼의 이메일 값을, 본문에 이름 값을 넣어 '○○님, 신청 고마워요!'를 만들어요.
  5. 테스트와 켜기
    Run once를 누르고 폼을 한 번 제출해 봐요. 시트에 줄이 생기고 메일이 오면 성공. 스케줄을 켜면 자동으로 돌아가요.

BEFORE · AFTER

이렇게 달라져요

✕ 전
신청이 올 때마다 메일함을 확인해 엑셀에 옮겨 적고, 안내 메일을 직접 보낸다
○ 후
폼 제출 → 시트에 자동 기록 → 신청자에게 자동 안내 메일
왜 좋아졌나요? 반복 작업이 0이 되고, 기록이 빠지거나 메일을 잊는 일이 없어져요.

COMMON MISTAKES

자주 하는 실수

  • ✕ 트리거 없이 액션부터 만든다
    → 항상 '무엇이 생기면'부터.
  • ✕ 테스트 없이 바로 켠다
    → Run once로 한 번 확인.
  • ✕ 무료 플랜 실행 횟수를 모른다
    → 스케줄 간격을 너무 짧게 잡지 않기.

MISSION

오늘의 실습 미션

🎯 위 단계대로 '폼 → 시트 → 메일' 시나리오를 만들고, 본인 이메일로 테스트 신청을 해 보세요.

미션용 프롬프트
Make로 [반복 업무]를 자동화하려고 해. 트리거와 모듈 순서, 각 모듈에서 설정할 값, 테스트 방법을 초보자도 따라 할 수 있게 단계별로 알려 줘.
