LEARNING LAB · 초급 08

피그마 오토 레이아웃 기초

글자가 길어져도 깨지지 않는 버튼·카드·리스트를 만드는 방법이에요.

초급UX/UI약 20분실습 포함

WHY

이 레슨에서 얻는 것

오토 레이아웃 없이 그린 화면은 글자 하나만 바뀌어도 하나하나 다시 맞춰야 해요. 오토 레이아웃은 '안쪽 여백과 간격 규칙'을 정해 두는 기능이라, 실제 앱처럼 내용이 바뀌어도 알아서 맞춰져요. 개발자에게 넘길 때도 훨씬 정확해져요.

CONCEPTS

먼저 알아둘 개념

오토 레이아웃

요소들을 가로·세로 방향으로 정렬하고, 간격과 안쪽 여백을 규칙으로 정하는 기능 (단축키 Shift + A)

패딩

프레임 안쪽 여백. 버튼이라면 글자와 버튼 테두리 사이 공간

간격(Gap)

요소와 요소 사이의 거리

Hug / Fill / Fixed

내용에 맞추기 / 부모 너비 채우기 / 고정 크기

STEP BY STEP

따라 하기 5단계

  1. 버튼 만들기
    텍스트 하나를 선택하고 Shift + A. 패딩을 좌우 20, 상하 12로 주고 배경색을 넣어요. 글자를 길게 바꿔 보면 버튼이 같이 늘어나요.
  2. 아이콘 + 글자 버튼
    아이콘과 텍스트를 함께 선택하고 Shift + A, 간격 8. 가운데 정렬로 맞춰요.
  3. 카드 만들기
    이미지, 제목, 설명을 세로 방향 오토 레이아웃으로 묶고 간격 12, 패딩 16. 너비는 Fixed, 높이는 Hug.
  4. 리스트 만들기
    카드를 세로로 여러 개 복제해 다시 오토 레이아웃(간격 12). 카드 하나를 지워도 나머지가 자동으로 붙어요.
  5. 너비 반응 확인
    카드 안의 텍스트를 Fill로 바꾸고 바깥 프레임 너비를 줄였다 늘려 보세요. 글자가 줄바꿈되며 카드가 늘어나면 성공이에요.

BEFORE · AFTER

이렇게 달라져요

✕ 전
글자 길이가 바뀔 때마다 버튼 크기와 위치를 손으로 다시 맞춘다
○ 후
버튼·카드·리스트를 처음부터 오토 레이아웃으로 만들고, 간격은 4의 배수(8·12·16·24)로 통일한다
왜 좋아졌나요? 내용이 바뀌어도 자동으로 맞춰지고, 간격 규칙이 일정해서 화면 전체가 정돈돼 보여요.

COMMON MISTAKES

자주 하는 실수

  • ✕ 겹친 요소를 오토 레이아웃에 넣는다
    → 겹쳐야 하는 배지 같은 요소는 Absolute position으로.
  • ✕ 간격을 13, 17처럼 제각각 준다
    → 4의 배수 규칙으로 통일.
  • ✕ 모든 걸 Fixed로 둔다
    → 텍스트는 Hug나 Fill로 둬야 반응해요.

MISSION

오늘의 실습 미션

🎯 자주 쓰는 버튼 1개와 카드 1개를 오토 레이아웃으로 만들고, 글자를 2배로 늘려도 깨지지 않는지 확인해 보세요.

미션용 프롬프트
피그마로 [화면 이름]을 오토 레이아웃으로 만들려고 해. 화면을 묶음 단위로 나누고, 각 묶음의 방향·간격·패딩·크기 설정(Hug/Fill/Fixed)을 표로 제안해 줘. 간격은 4의 배수로.
